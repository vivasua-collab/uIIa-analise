# 📖 Документация: Аналитический портал ИИ в России

## Описание проекта

Интерактивная презентация-аналитика российского рынка искусственного интеллекта с:
- Анализом 50+ компаний по 5 технологическим направлениям
- Расчётами развёртывания On-Premise решений
- Анализом рисков ИИ-пузыря
- Адаптивным интерфейсом с двумя режимами отображения

---

## 🚀 Быстрый старт

### Системные требования

| Компонент | Минимальная версия |
|-----------|-------------------|
| Node.js | 18.x+ |
| Bun | 1.x+ |
| npm | 9.x+ (опционально) |

### Установка

```bash
# 1. Клонирование репозитория
git clone https://github.com/vivasua-collab/uIIa-analise.git
cd uIIa-analise

# 2. Установка зависимостей
bun install

# 3. Запуск в режиме разработки
bun run dev

# 4. Сборка для продакшена
bun run build

# 5. Запуск продакшен-версии
bun run start
```

### Доступные скрипты

| Скрипт | Описание |
|--------|----------|
| `bun run dev` | Запуск в режиме разработки (порт 3000) |
| `bun run build` | Сборка для продакшена |
| `bun run start` | Запуск продакшен-сервера |
| `bun run lint` | Проверка кода ESLint |

## 📝 Поддержка и развитие

### Добавление новых компаний

1. Откройте `src/app/page.tsx`
2. Найдите массив `techData.{категория}.leaders` или `.others`
3. Добавьте объект компании:

```typescript
{
  name: 'Название компании',
  inn: '1234567890',
  url: 'https://example.com',
  description: 'Описание деятельности',
  features: ['Фича 1', 'Фича 2'],
  status: 'active' as const,
  revenue: '100 млн ₽',
  alsoIn: ['LLM', 'Аудио'] // если мульти-направленная
}
```

### Обновление данных рынка

1. Обновите константу `marketOverview` в начале файла
2. Укажите источник данных в поле `*Note`
3. Обновите `checkpoint.md` с новыми источниками
