### Новая архитектура данных

#### Prisma Schema (prisma/schema.prisma)

```prisma
// Компания (расширение существующей структуры)
model Company {
  id          String   @id @default(cuid())
  name        String
  inn         String?  @unique
  url         String
  description String
  status      CompanyStatus @default(active)
  revenue     String?
  category    String   // llm, audio, video, dl, gen
  features    String   // JSON array как строка
  alsoIn      String?  // JSON array как строка
  isCustom    Boolean  @default(false)  // добавлена пользователем?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  comments    Comment[]
  tags        CompanyTag[]
}

// Комментарий
model Comment {
  id        String   @id @default(cuid())
  content   String
  author    String?  // опционально, если без авторизации
  companyId String
  company   Company  @relation(fields: [companyId], references: [id], onDelete: Cascade)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}

// Тег
model Tag {
  id        String   @id @default(cuid())
  name      String   @unique
  color     String?  // цвет тега (hex или tailwind класс)
  companies CompanyTag[]
}

// Связь Компания-Тег (many-to-many)
model CompanyTag {
  companyId String
  tagId     String
  company   Company @relation(fields: [companyId], references: [id], onDelete: Cascade)
  tag       Tag     @relation(fields: [tagId], references: [id], onDelete: Cascade)

  @@id([companyId, tagId])
}

enum CompanyStatus {
  leader
  active
}
```

### API Routes

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/api/companies` | GET | Получить все компании |
| `/api/companies` | POST | Создать компанию |
| `/api/companies/[id]` | PUT | Обновить компанию |
| `/api/companies/[id]` | DELETE | Удалить компанию |
| `/api/comments` | GET | Комментарии по companyId |
| `/api/comments` | POST | Создать комментарий |
| `/api/comments/[id]` | DELETE | Удалить комментарий |
| `/api/tags` | GET | Все теги |
| `/api/tags` | POST | Создать тег |
| `/api/tags/search` | GET | Поиск компаний по тегам |
| `/api/export/excel` | GET | Экспорт в Excel |

## Технические решения

### Хранение данных

- **SQLite** - достаточно для локального использования и небольших команд
- При необходимости миграция на PostgreSQL простая (Prisma абстрагирует)

### Валидация

- **Zod** для валидации форм и API запросов

### Авторизация (опционально)

- NextAuth.js можно добавить позже
- Без авторизации: анонимные комментарии, модерация не требуется

### Excel экспорт

- **xlsx** (SheetJS) - популярная библиотека
- Альтернатива: **exceljs** (более гибкий)

## Риски и ограничения

| Риск | Решение |
|------|---------|
| Дублирование компаний при добавлении | Проверка по ИНН и названию |
| Спам в комментариях | Без авторизации - модерация или ограничение |
| Перегрузка тегами | Ограничение количества тегов на компанию |
| Большой объём данных | Пагинация, ленивая загрузка |
