# Промпт для исследования ИИ-компаний России

Используйте этот промпт с любой нейросетью (GPT-4, Claude, YandexGPT, GigaChat) для исследования и сбора данных о компаниях.

---

## Основной промпт

```
Ты - аналитик российского рынка искусственного интеллекта. Твоя задача - исследовать компанию и подготовить данные для добавления в аналитическую базу.

## Компания для исследования
Название компании: [НАЗВАНИЕ]
ИНН (если известен): [ИНН]
Сайт: [URL]

## Критерии отбора
Компания должна соответствовать ВСЕМ критериям:
1. Российская юрисдикция (регистрация в РФ)
2. Деятельность в сфере ИИ/ML/DL
3. Продукты или решения на базе ИИ
4. B2B или B2G направленность (не только потребительские сервисы)

## Категории ИИ-решений
Выбери ОДНУ основную категорию:

### LLM (Чат-боты) - ключ "llm"
- Большие языковые модели
- Чат-боты и виртуальные ассистенты
- RAG-системы
- Корпоративные ИИ-ассистенты
- Генерация текста

### Аудио-аналитика - ключ "audio"
- Распознавание речи (ASR/STT)
- Синтез речи (TTS)
- Речевая аналитика
- Голосовые боты
- Голосовая биометрия

### Видео-аналитика - ключ "video"
- Компьютерное зрение (Computer Vision)
- Распознавание лиц
- Видеоаналитика безопасности
- OCR (распознавание документов)
- Промышленная видеоаналитика

### Глубокое обучение - ключ "dl"
- ML-платформы
- MLOps решения
- Обучение нейросетей
- GPU-инфраструктура
- Data Science консалтинг

### Генеративный ИИ - ключ "gen"
- Генерация изображений
- Генерация видео
- Генерация аудио
- Генерация кода
- Мульти-модальные модели

## Данные для сбора

### Обязательные поля:
1. **name** - Полное название компании
2. **inn** - ИНН компании (найти в открытых источниках)
3. **url** - Основной сайт компании
4. **description** - Описание деятельности (2-3 предложения)
5. **features** - Массив из 4 ключевых технологий/продуктов
6. **status** - "leader" или "active"

### Опциональные поля:
7. **revenue** - Выручка или оценка положения на рынке
8. **alsoIn** - Дополнительные категории (массив)
9. **isPartner** - true если компания является партнёром

## Критерии для status="leader":
- Выручка > 500 млн ₽ ИЛИ
- Известность в отрасли ИЛИ
- Уникальные технологии ИЛИ
- Государственное участие ИЛИ
- Международное присутствие

## Формат ответа

Верни ТОЛЬКО JSON валидного формата:

```json
{
  "companies": [
    {
      "name": "Название компании",
      "inn": "1234567890",
      "url": "https://example.com",
      "description": "Описание деятельности компании в 2-3 предложениях.",
      "features": ["Технология 1", "Технология 2", "Продукт 3", "Решение 4"],
      "status": "leader",
      "revenue": "1.5 млрд ₽",
      "alsoIn": ["Аудио", "Видео"],
      "categoryKey": "llm",
      "isPartner": false
    }
  ]
}
```

Если компания НЕ соответствует критериям, верни:
```json
{
  "rejected": true,
  "reason": "Причина отклонения"
}
```

## Источники для поиска информации:
- Официальный сайт компании
- Rusprofile.com (для ИНН и выручки)
- TAdviser (обзоры ИИ-рынка)
- CNews, TAdviser (новости)
- Хабр, VC.ru (статьи о компаниях)
- GitHub (open-source проекты)
```

## Советы по использованию

1. **Проверяйте ИНН** через Rusprofile или nalog.gov.ru
2. **Сверяйте выручку** с открытыми источниками
3. **Проверяйте актуальность сайта** перед добавлением
4. **Избегайте дубликатов** - проверяйте по названию и ИНН
5. **Используйте Web Search** для актуальных данных

---

## Интеграция с базой данных

После получения JSON от нейросети:

1. Сохраните в файл `prisma/companies-to-add.json`
2. Запустите импорт: `bun run db:import`
3. Проверьте результат в интерфейсе
4. Экспортируйте в seed: `bun run db:export`
